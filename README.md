# Матеквест — математическая экспедиция

Публичная игра: https://mathquest-expedition.vercel.app

## Как играть
1. Нажмите «Начать заново», зарегистрируйтесь по email и паролю (от 10 символов).
2. Решайте вопросы. Можно вводить целые числа, десятичные с точкой/запятой и дроби вида 3/4.
3. Верный ответ даёт 10 поинтов. На каждом уровне 10 вопросов. Для перехода нужно 8 верных ответов (80 поинтов).
4. Третья ошибка завершает текущую попытку. Пройденные уровни и лучшие результаты сохраняются. Темы и уровни можно выбирать в любом порядке через кнопку «Уровни».
5. «Продолжить» загружает прогресс из Neon. Каждый ответ сохраняется на сервере.
6. После прохождения всех 35 разных уровней скачайте PDF-диплом. Откройте PDF и выберите «Печать».
7. В настройках можно менять яркость, фон, звук и анимацию; настройки сохраняются в браузере.

## Что работает самостоятельно
Vercel обслуживает HTML/CSS/JS и серверные API. Neon хранит аккаунты, сессии, прогресс и дипломы. Компьютер разработчика для работы сайта не нужен. Необходимо сохранять аккаунты сервисов активными и не превышать их тарифные лимиты.

## Подсказки
После ошибки показывается проверенное объяснение с формулой без полного решения. Если Vercel AI Gateway активирован, модель OpenAI классифицирует ошибку и выбирает подходящий учебный акцент. Сырой ответ модели не выводится пользователю, поэтому она не может раскрыть решение. При недоступности ИИ остаётся режим формул с явной подписью.
На момент первой проверки AI Gateway потребовал банковскую карту для активации кредитов. Вводить её нужно только в панели Vercel, не в код или чат.

## Технологии и структура
- `public/`: адаптивный интерфейс на чистом HTML, CSS, JavaScript; SVG-остров, анимации, Web Audio.
- `lib/questions.mjs`: 35 генераторов по 10 заданий, проверка чисел и игровая логика.
- `api/`: серверные Vercel Functions; Better Auth; транзакционное сохранение с блокировкой строки и проверкой версии.
- `lib/auth.mjs`: Better Auth + PostgreSQL Neon, защищённые cookies и ограничение частоты запросов в базе.
- `scripts/migrate.mjs`: создание таблиц Better Auth и игры при сборке.
- `lib/diploma.mjs`: PDFKit, встроенный шрифт с кириллицей. Диплом доступен только победителю.
- `test/`: проверки правил и математических заданий.

## Повторное развёртывание простыми шагами
Требуется Node.js 24+ и аккаунт Vercel. В этой рабочей среде CLI использовал отдельный каталог конфигурации; на личном компьютере этот флаг не нужен.

```bash
npm ci
npx vercel login
npx vercel link --project mathquest-expedition --scope asadbek1981uz-5301
npx vercel project inspect --non-interactive
npx vercel env pull .env.local --yes
npm test
npx vercel deploy --prod
```
Не создавайте Neon повторно: база `mathquest-db` уже подключена. При переносе в другой проект создайте новую базу через Marketplace и настройте переменные ниже.

Переменные серверной среды: DATABASE_URL, BETTER_AUTH_SECRET (случайная строка), BETTER_AUTH_URL (точный публичный адрес), AI_GATEWAY_MODEL. Vercel предоставляет OIDC для AI Gateway автоматически. Никогда не добавляйте .env.local в репозиторий. При смене домена обновите BETTER_AUTH_URL и перевыпустите deployment.

Для локальной статической сборки: `node scripts/build.mjs`. Полная сборка `npm run build` также выполняет миграции и требует доступа к PostgreSQL. Миграции успешно выполняются на Vercel. В средах без прямого TCP-доступа к Neon запускайте их в Vercel, а не отключайте проверку TLS.

## Проверка
14 автоматических тестов проверяют задания, прохождение в любом порядке, лучшие результаты, условия диплома и правила модерации. Интерфейс проверен в браузере с тестовыми ответами API: темы, выбор уровня, форма блокировки и сообщение заблокированному игроку. На рабочем сайте проверены вход разработчика, регистрация игрока, сохранение ответа, защита от повторного запроса, предупреждение и отчёт об отсутствии, временная/постоянная блокировки, снятие/истечение блокировки и загрузка PDF. Временный тестовый аккаунт удалён. Существующий прогресс трёх игроков перенесён с сохранением результатов и архивной копии.

## Ограничения
Нет восстановления пароля по почте и подтверждения email: почтовый сервис не подключён. При регистрации используйте пароль, который сможете сохранить. Диплом игровой и не является образовательной квалификацией. Фоновая музыка не загружается: короткие звуки синтезируются браузером. Иконка OpenAI используется для обозначения поставщика ИИ, игра не является официальным продуктом OpenAI.
